Sports analytics

  • Match video analysis

    Python, YOLO detection, tracking, pitch homography, expected goals

    Takes a full match filmed from one camera and produces team and player statistics, expected goals, set pieces and a timeline of key moments with highlight clips. Players and ball are detected, tracked, split by team and mapped onto the pitch, then a written rulebook defines every statistic and how far to trust it. A local launcher runs the whole pipeline.

  • Season forecasts and GPS load

    Python, Streamlit, Monte Carlo simulation, tested package

    Scrapes fixtures and results, builds league tables and simulates the remaining games to forecast the final standings. A second part tracks GPS data from my own training and matches: distance, sprints, top speed, load and how much sprinting is left in the second half. Analysis lives in a tested Python package that the dashboards call.

Applied machine learning

  • RAG architecture comparison

    Python, sentence-transformers, ChromaDB (HNSW), GPT-4o-mini

    Four retrieval-augmented generation pipelines for product recommendations, compared on the same test queries: cosine-similarity retrieval and a ChromaDB vector store, each with and without an intent layer that applies business rules such as exclusions and age limits. An evaluation harness reports latency, token cost, retrieval counts and answer quality.

  • Document retrieval API

    Python, FastAPI, TF-IDF, cosine similarity

    A permission-aware retrieval API over a JSON knowledge base, with configurable top-k and similarity threshold, REST endpoints and interactive documentation.

  • Personal finance pipeline

    Python, HTML and JavaScript, Chart.js

    Monthly bank exports go through a Python pipeline that removes duplicates and categorises transactions into one store, which is encrypted before it is committed. An HTML dashboard shows the results and can ingest new files in the browser, and a notebook walks through each step.

Research code

    Python, PyTorch, MediaPipe landmarks

    Code from my INESC TEC fellowship: dataset preparation for CK+ and RaFD, teacher training, and response-based distillation into small student models that use facial landmarks.

  • Emotion silhouettes

    Python, CNNs, face detection

    Training and testing CNNs on original face images and on a landmark-based “emotion silhouette” representation, as studied in my thesis.
